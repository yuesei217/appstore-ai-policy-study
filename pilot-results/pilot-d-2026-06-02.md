## Follow-Up Investigation: iTunes RSS `/date=` Parameter

The script flagged that `/date=2025-11-13/` returned HTTP 200 with "Nov 2025 date references."  
Manual check confirmed this is a **false positive**:

```bash
# Feed updated date from /date=2025-11-13/ response:
Feed updated: 2026-06-02T00:06:54-07:00   ← TODAY, not Nov 2025

# Top 3 from /date=2025-11-13/:    Top 3 from current (no date):
#1 ChatGPT                          #1 ChatGPT
#2 Planet Fitness                   #2 Planet Fitness
#3 Claude by Anthropic              #3 Claude by Anthropic
```

**Finding:** The `/date=` URL segment is silently ignored by Apple's RSS endpoint. It returns current chart data regardless of the date value provided. The "Nov 2025 date references" in the response body were from app descriptions, not the chart timestamp.

## Revised Conclusions

### What's actually available for free

| Source | Verdict | Notes |
|---|---|---|
| iTunes RSS (current) | ✅ Real-time top charts | No historical parameter |
| iTunes RSS `/date=` parameter | ❌ Ignored | Returns today's data regardless |
| Wayback Machine — iTunes chart RSS | ⚠️ Sparse | 20 snapshots across 2.5 years; 2 in Nov 2025 (both Nov 21) |
| Wayback Machine — App Store charts page | ❌ Not archived | 0 snapshots found |
| AppFollow (public) | ❌ 404 | URL no longer valid |
| Any continuous daily ranking source | ❌ Paid-only | Sensor Tower, AppTweak, Appfigures, data.ai, Apptopia |

### What the Wayback snapshots can support

The 20 Wayback snapshots give us 20 **point-in-time cross-sections** of the top-100 chart:

| Use case | Feasible? |
|---|---|
| Continuous time-series / panel analysis | ❌ Only 20 time points over 2.5 years |
| DiD with daily/weekly granularity | ❌ Insufficient density |
| Pre vs. post policy snapshot comparison (crude) | ⚠️ Possible with only ~2 pre and ~3 post data points |
| Identifying whether an app was in top 100 at a specific date | ✅ For the dates we have |

### Revised Pilot D Verdict

**PARTIALLY available (sparse)** — not "paid-only" as initially concluded.  
- Wayback Machine contains genuine iTunes chart snapshots with top-100 app rankings
- In the Nov 2025 policy window: 2 snapshots exist (both from Nov 21, 2025 — 8 days post-policy)  
- Pre-policy data is very sparse: nearest snapshots are Jul 2025 and Apr 2025
- Not sufficient for rigorous panel/event-study design, but usable for crude before/after snapshot comparisons
- For rigorous daily ranking data: still requires paid source
