## Diagnostic Follow-Up

After seeing page 2 return empty for all apps, we ran additional checks to distinguish between "no more data exists" vs "pagination URL is broken."

### Test 1: Three pagination URL formats for Grammarly (id=1158877342)

```bash
# Format 1: page in path with country param
curl "https://itunes.apple.com/rss/customerreviews/page=2/id=1158877342/sortBy=mostRecent/json?cc=us"
# → entries: 0

# Format 2: page at end of path
curl "https://itunes.apple.com/rss/customerreviews/id=1158877342/page=2/sortBy=mostRecent/json"
# → entries: 0

# Format 3: no pagination param (page 1 baseline)
curl "https://itunes.apple.com/rss/customerreviews/id=1158877342/sortBy=mostRecent/json"
# → entries: 0
```

**Finding:** All three formats return 0 entries on page 2. The RSS feed is not paginated — it returns a maximum of 50 reviews total (1 page), regardless of URL format.

### Test 2: XML format for pagination link inspection (Grammarly)

```bash
curl "https://itunes.apple.com/rss/customerreviews/id=1158877342/sortBy=mostRecent/xml"
```

Relevant excerpt from response:
```xml
<link rel="first" href=""/>
<link rel="last" href=""/>
<link rel="previous" href=""/>
<link rel="next" href=""/>
```

**Finding:** All pagination links are empty strings. Apple has disabled pagination in the RSS feed. The 500-review limit that was historically documented (10 pages × 50) no longer applies — the feed is capped at 50.

### Test 3: AI Writer app metadata verification

To rule out the possibility that AI Writer (id=1639845219) was delisted:

```bash
curl "https://itunes.apple.com/lookup?id=1639845219&country=us"
```

**Finding:** The app is live and was last updated 2026-04-22. The RSS feed returning 0 entries is not due to the app being removed. Most likely the app's US-storefront review volume is too low to populate the RSS feed.

---

## Conclusions

1. **RSS pagination is broken/deprecated.** The feed now returns at most 50 reviews regardless of page parameter. The `<link rel="next">` pagination links are empty for all tested apps.

2. **Maximum lookback via RSS: ~10 days** (Grammarly, the slowest-velocity large app). High-velocity apps like ChatGPT and Spotify only reach back ~1 day.

3. **Small apps return 0 reviews** via RSS, even when the app has thousands of lifetime ratings. The RSS feed appears to require a minimum review velocity threshold.

4. **Nov 2025 data is unrecoverable via free public RSS.** The gap between the best reachable date (2026-05-20) and the policy date (2025-11-13) is ~6 months.

5. **Verdict: RED.** Review-based DiD is not viable with the public RSS API.
