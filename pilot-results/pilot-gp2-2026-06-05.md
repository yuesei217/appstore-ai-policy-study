## Uptodown: Best Available Source

Uptodown is the only source returning accessible version data with dates. Structure of each entry:

```html
<div data-url="..." data-version-id="1176657319" data-extra-url="download">
  <span class="version">1.2026.146</span>
  <span class="date">Jun 4, 2026</span>
</div>
```

### ChatGPT — Uptodown page 1 (20 entries)

| Version | Date |
|---|---|
| 1.2026.146 | Jun 4, 2026 |
| 1.2026.139 | May 31, 2026 |
| 1.2026.125 | May 24, 2026 |
| … | … |
| 1.2026.069 | Apr 9, 2026 |

→ 20 entries cover **Apr–Jun 2026 only (~3 months)**. ChatGPT releases ~2 versions/week.

→ 20 entries cover **Apr–Jun 2026 only (~6 weeks)**. Spotify releases ~3 versions/week.

### Pagination limitation

The `?p=N` URL parameter is accepted (HTTP 200) but returns the same 20 entries regardless of page number — pagination is JavaScript-based (infinite scroll or "load more"). All tested API endpoint formats returned 404:

```
/android/apps/{code}/versions/json/{last-id}  → 404
/android/apps/versions/json?page=2&code=…     → 404
/android/versions-page/2                       → 404
```

Accessing older versions requires a JavaScript-capable browser (Selenium/Playwright) or Wayback Machine snapshots of Uptodown pages.

---

## Additional Finding: Wayback CDX Rate-Limited

The Wayback CDX API returned HTTP 503 for all queries in this session. This is consistent with the rate-limiting observed in earlier pilots. It does not mean there are no snapshots — once the rate limit resets, Uptodown archives from 2021–2024 may be accessible via Wayback, which would provide version lists from those historical pages.

This path remains **untested** and worth a follow-up once CDX recovers.

## Verdict

**All three apps: RED** via static scraping with current session constraints.

The best accessible source (Uptodown) provides 20 version entries with dates, but covers only the most recent 2–3 months for high-update apps. Reaching the 2021–2025 research window requires one of:

| Path | Feasibility | Notes |
|---|---|---|
| Uptodown with browser automation (Selenium/Playwright) | ⚠️ Possible | Engineering overhead; bot-detection risk |
| Wayback Machine snapshots of Uptodown (once CDX resets) | ⚠️ Conditional | Depends on archival coverage for Uptodown pages |
| Paid sources (Appfigures, AppFollow) | ✅ Reliable | ~$100–500/month |
| APKPure / APKMirror | ❌ | Cloudflare blocks automated access |
